가산수당 계산 기준
구분 가산률 비고
연장근로 50% 일일 8시간 초과 또는 주 40시간 초과 시
야간근로 50% 22:00~06:00
휴일근로 50% 공휴일 근로
  • • 휴일은 빨간날(공휴일)만 해당하며, 토요일은 휴일이 아닙니다.
    • 가산수당 중복 적용 기준
    조건 가산률 계산식
    연장/야간/휴일 중 1가지 1.5배 1.0 + 0.5
    연장+야간 또는 야간+휴일 또는 휴일+연장 2.0배 1.0 + 0.5 + 0.5
    휴일+연장+야간 2.5배 1.0 + 0.5 + 0.5 + 0.5
    연장근로 판단 기준
    • • 하루 기준(00:00~24:00): 실근로가 8시간을 넘는 부분은 연장으로 봅니다.
    • • 주간 기준: 주 40시간을 넘는 부분은 연장으로 봅니다.
      (일별 연장(8시간 초과)은 별도로 계산되고, 주간 기준에는 포함되지 않습니다.)
    • • 연장근로 한도: 연장근로 시간은 1주 12시간을 초과할 수 없습니다.
    휴게시간 규칙
    • • 4시간 초과: 30분 이상 휴게
    • • 시간대가 나뉜 경우: 각각의 근무에 대해 휴게를 계산합니다.
    • • 배치 방식: 4시간 근무 후 30분 휴게를 반복 배치합니다.
    행정해석
    • • 근기68207-402 (2003.3.31): 역일을 넘어 계속 근로가 이어지면 전일 근로의 연장으로 보되, 익일 소정근로 시업시각 이후의 근로는 익일의 소정근로로 봅니다.
    • • 주휴일에 시작된 근로가 익일로 이어지는 경우, 익일 시업시각 이전은 전일(휴일) 근로로 보고 휴일근로수당을 지급합니다.
    • • 익일 시업시각 이후의 근로는 전일 연장으로 보지 않습니다.
    • • 00:00에 새로 시작한 근로는 전일 연장이 아닙니다.
    • • 주휴일 전일에 근로를 개시하여 역일상 휴일까지 근로를 한 경우는 하나의 근로로 보고 휴일근로수당 없이 연장·야간수당만 적용합니다.

    관련 법령
    • • 근로기준법 제56조 (연장·야간 및 휴일 근로): 연장·야간·휴일근로에 대해 통상임금의 50% 이상 가산, 휴일근로 8시간 초과분은 100% 가산.
    • • 근로기준법 제50조 (근로시간): 1일 8시간, 1주 40시간(휴게 제외).
    • • 근로기준법 제53조 (연장근로 제한): (합의 시) 1주 12시간 한도.
    • • 근로기준법 제57조 (보상휴가제): 근로자대표와 서면합의로 가산수당 대신 휴가로 대체 가능.
